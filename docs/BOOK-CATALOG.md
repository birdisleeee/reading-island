# 开放书库搜书与导入

本功能以按需工具运行在共读岛的 Cloudflare 后端。公共服务已于 **2026-10-27** 改为服务内的官方书目快照检索，再按所选版本联网核验和下载；现有 APK 使用同一网页后端。单文件上限为 10 MiB，详见[发布记录](PUBLIC-SERVICE-RELEASE.md)和下方[静态官方书目](#static-catalog)。旧版或缺少快照的自行部署仍可按下文的 Gutendex 路径回退。

## 自己搜书

书架 → 添加书籍 → 从开放书库搜书导入。输入书名或作者，选择语言，搜索并核对候选书籍的作者、语言和来源。新版先勾选一个版本，再选择分组并点击“导入所选书籍”；导入选项只在有结果时出现。保存成功后点击“刷新书架”。没有结果时可以调整关键词，或继续使用文件上传。

第一版通过 [Gutendex](https://gutendex.com/) 检索 Project Gutenberg 的开放作品，下载使用其[官方列出的镜像](https://www.gutenberg.org/MIRRORS.ALL) `gutenberg.pglaf.org`，仅接收包含完整起止标记的 UTF-8 TXT 原文。作品是否适合在所在地使用，应按来源及版本确认。它不是任意网站搜索引擎，不保证能找到现代小说、某个译本或所有中文书。

## 让普通模型帮忙

设置 → AI 接入与人物预设 → 可选书库工具 → 开启“允许 AI 搜书并导入”，重新测试并保存。默认关闭；已有配置不会自动增加权限。

在一本书的讨论议题中，可以说“帮我找 Pride and Prejudice”，核对 AI 返回的版本，再说“导入第一个”。模型调用 `search_books(query, language?)` 和 `import_book(candidate_id, group_id?)`，后端直接下载文件并存入当前用户书架。文件全文不需要模型重新生成，不以摘要冒充原书。效果取决于模型的工具调用能力；也可以直接用网页入口选择和导入。

需要先有一本书及讨论议题才能通过对话调用；空书架可以先用网页搜书入口。定时主动共读不会获得搜索和下载工具；已有 Agent 的上传、原文读取和回复接口保持独立。

## 额度与失败处理

- 每账号每日最多 10 次新检索、3 次下载尝试，UTC 零点（北京时间 08:00）重置。失败尝试也计数，同一关键词和语言的最新结果缓存 10 分钟，命中缓存不增加新检索次数。
- 最多返回 6 个候选，下载最多 10 MiB。已上线版本的外部检索最多等待 20 秒、下载最多 60 秒，不自动重试；静态书目候选的验证流程见下文。相同来源书籍导入成功后再次提交返回已有书，不重复下载或创建副本。
- 书籍、原件、冻结正文和辅助记录均占当前用户原有额度；公共服务的审批、暂停及书籍/存储配额继续生效。失败可能保留隐藏预约和存储预留，以便同一本书安全重试。
- 模型的搜索和导入续答消耗用户自己的模型余额及每日服务请求额度；手动搜书不调用模型。当前已上线版本的外部检索只发送用户提供的书名/作者和语言，不发送书库正文、Key 或会话凭据；本地静态书目候选优先在服务内检索。

实现限制了书源、下载主机、文件体积、响应类型和完整性；工具不接收任意下载 URL。首次下载后的副本属于当前用户，不给其他账号共享文件或权限。

## 接口与自行部署

已登录读者可 POST `/api/book-catalog/search`，正文 `{ "query": "书名或作者", "language": "zh" }`；`language` 可省略，或为 `zh/en`。返回候选 `candidate_id/title/author/languages/source_url`。

POST `/api/book-catalog/import`，正文 `{ "candidate_id": "上一步的候选ID", "group_id": "可省略的本人分组ID" }`。只接受本人此前检索结果或同一本书的已有导入预约，不接受 owner、URL、正文或已有书籍 ID。接口与既有身份验证同源，未登录、跨用户、跨站和超额请求会被拒绝。

网页保存的 `allow_catalog` 随模型配置加密保存并绑定测试凭据；高级服务端配置可使用 `MODEL_ALLOW_CATALOG=true`，网页已保存的设置优先。普通模型工具每回合最多新增一本，和原有 `add_book` 共用新增次数限制。

来源规则：[Gutendex API](https://gutendex.com/) · [Gutenberg 自动访问规则](https://www.gutenberg.org/policy/robot_access.html) · [镜像说明](https://www.gutenberg.org/help/mirroring.html)。

## 查询与导入列表（2026-10-24已发布）

网页手动搜书不调用 AI，无需先接入模型。新版会先把查询或导入提交为后端持久任务，关闭窗口、刷新或退出应用不会取消已接收的任务；重新打开“搜书与导入列表”可查看最近 20 条记录及结果。失败不会自动重试，点击重试才产生新任务；同一本书使用原来的导入身份避免重复创建。候选结果可在 24 小时内用于导入，过期后重新搜索。

任务在原有用户专属 DO 内保存，与主动议题共享闹钟调度；没有新增轮询爬虫或书库镜像。已结束的旧记录会按上限清理；处理中任务和它引用的查询结果不会被清理。仅在列表打开、页面可见且有未结束任务时轮询，完成后停止。账号被暂停或权限不可用时不继续下载。

## 书源故障检查（2026-10-25已发布）

“未找到版本”和“请求失败”是不同结果：只有书源返回有效 JSON 且可导入候选为空，才能说明本次没有匹配版本。新候选分别提示超时、网络连接、书源 HTTP 错误、上游限流、拒绝跳转、无效响应与共读岛内部服务失败。查询/导入列表中的失败记录可展开“故障信息”，查看来源、阶段、HTTP 状态（如有）、耗时及发生时间。

旧版把多种错误合并为一个错误码，没有保存上游状态和耗时。没有当次日志时不能确定它属于哪一种，也不能拿后来成功的查询反推当时一定正常。故障时间采用任务的更新时间；提交时间不代表整段时间都在等待书源。

维护者可以在项目目录执行一次匿名书目检查：

```sh
node tools/catalog-health.mjs
node tools/catalog-health.mjs The Painted Veil
```

每次仅从执行机器请求一次固定书源元数据，最多等待 20 秒，无自动重试，不读取账号凭据，不下载电子书，也不消耗读者的共读岛配额。输出仅含检查结果、候选数量或安全诊断。执行机器与线上 Cloudflare 的网络不同，这个检查不能代替实际失败任务的诊断。一次成功也不保证后续始终可用。

先核对失败任务的分类；遇到限流或暂时超时应稍后由用户手动重试，不循环点击或开启后台探测。成功空结果可调整书名或作者。不要为排错创建真实书籍、调用模型或增加日志收集服务。这些维护变更已随2026-10-25公共服务更新上线。

## 静态官方书目（2026-10-27 已上线）

应用打包 Project Gutenberg 官方 CSV 中 `Type=Text` 的元数据快照：日期 **2026-10-25**，**78,423 条**，**7,941,383 字节（约 7.94 MB）**。快照只含书目 ID、标题、作者和语言，不含电子书正文。普通搜索由用户专属 Durable Object 通过 `ASSETS` 读取此文件，在服务内匹配标题和作者，**不向外部书源发送 query**。同一运行实例会缓存校验后的书目。它是固定日期的书目，不能保证每条记录仍有可导入的文件，也不保证涵盖所有作品。

部分常见中文书名和作者名有检索别名。例如“面纱”可找到 `64682 / The Painted Veil / en`，表示这本作品的英文版本，不会制造或承诺中文译本。选择中文语言筛选时，不会把英文候选混入；可以切换全部语言查看，导入前仍应核对语言和版本。

只有静态资源返回 **404**（例如旧版自行部署没有打包快照）时，才回退到原来的固定 Gutendex 搜索接口。静态资源损坏、UTF-8 无效、记录结构或数量不符、读取失败，会返回共读岛服务失败，不能当作“未找到版本”，也不会悄悄改向外部检索。

选择导入后，才请求该书籍 ID 对应的机器可读 RDF：核对所选记录 ID、该记录的 `Public domain in the USA.` 权利声明及 UTF-8 TXT 格式；RDF 最多 256 KiB、等待 20 秒。通过后再下载所选书籍的 TXT，仍最多 10 MiB、等待 60 秒，并检查 UTF-8 和完整起止标记。书目的语言和权利声明不能替代使用者所在地的版本核对。验证不通过不下载正文；这个流程没有自动重试。

原有每天 10 次新检索、3 次导入尝试及失败计次保持。一次所选导入的 RDF 验证和 TXT 下载合计为一次导入尝试；命中已有搜索缓存或已完成的导入仍不重复扣次。任务队列、历史结果、账号隔离、审批和存储配额保持，不新增搜索引擎、数据库或定时抓取任务。

正常 `npm run build` 只复制已提交的快照，构建过程不联网。快照由维护者按需获取官方机器可读 CSV，再运行本地生成脚本；更新方法、原始来源、哈希和署名见 [catalog/README.md](../catalog/README.md)。已有 `catalog-health.mjs` 仍是从执行机器直接检查一次 Gutendex 的维护工具，不代表静态快照搜索路径或 Cloudflare 现场测试。网络下载仍需使用者实机复验。
