# 共读岛使用说明

共读岛让你和自己的 AI 围绕书籍持续交流。可以从原文摘录聊起，也可以单独讨论人物、故事、结局和自己的看法；开启定时共读后，AI 还会从你指定的书架范围中发起新议题。

这份说明适合只有模型 API Key、没有 Agent 的使用者。已有 Agent 请看 [Agent 接入手册](AGENT-GUIDE.md)；还没决定安装方式，请先看 [项目介绍](../README.md#安装与使用选择适合你的方式)。

## 1. 进入自己的书架

### 使用制作者的网页或 APK

打开 [公共网页版](https://reading.nyachu.site/app)，或从 [官方下载入口](https://reading.nyachu.site/download/app.apk)安装 Android APK。APK 需要 Android 8.0 或更新版本，联网访问同一个公共服务；网页和 APK 使用同一套账号与书库。

在登录页下方点击 **注册账号并申请公共服务**，填写账号、密码、称呼，可选填写用于接收开发者服务通知的邮箱，然后提交，等待人工审核。初始开放 3 个获批名额，是否获批以账号页面为准。待审核账号显示“待审核批准额度中”，此时尚未分配书库额度；点击 **刷新审核结果** 查看状态，获批后即可点击 **进入我的书架**，**不需要额外申请码**。登录状态失效时，使用注册时的账号和密码重新登录。申请不会触发邮件或系统通知，请回到页面查看状态。

公共服务由制作者提供网页、APK 和限额存储，你自行提供模型 Key 和余额。获批后在账号页面查看具体配额；需要更多额度时提交扩容申请，审核前额度保持原值。规则见 [公共服务说明](../public-service/README.md)。

### 使用自己的站点

按 [部署入门](START-HERE.md)创建站点，再使用自己配置的访问密码登录。默认自部署是单读者实例，不走公共服务的申请、审批和名额流程。已有网站接入自己的账号系统时，按宿主网站的登录方式进入。

## 2. 连接阅读伙伴

1. 打开 **设置 → AI 接入与人物预设**。
2. 选择 DeepSeek 或兼容接口，填写自己的模型 API Key。需要模型 API 平台的 Key 和可用余额，仅有网页聊天账号不能替代 Key。兼容接口还要核对完整 Chat Completions 地址和模型名；所选模型需要支持共读使用的工具调用。
3. 给伙伴起一个称呼。可选填写人物预设和共读风格，例如：“交流自然，关注人物动机；愿意提出不同理解，并结合原文说明理由。”
4. 点击 **测试连接**。成功后点击 **保存并开始共读**，再关闭设置。

测试会向所选模型发送一段原创示例短文，检查文字回复和原文工具，通常产生两次小型 API 请求，使用你自己的模型余额；不会把现有书库发送给测试。成功或失败都会在表单中显示，失败时按提示检查 Key、余额、地址、模型及工具支持情况。修改配置后需要重新测试。

Key 由后端加密保存。再次打开设置时不会显示原 Key，已有 Key 时留空可沿用；页面尚未连接真实 AI 时，讨论中会明确显示 **Mock 模拟回复**。只有模型 Key 的模式使用当前议题的有限历史，不提供独立 Agent 的长期记忆。

## 3. 放入书籍，开始阅读

在书架点击 **＋** 添加书籍，选择文件并填写书名、作者、分组等资料。可以先用仓库的 [原创示例短文](../examples/sample-book.txt)熟悉流程，再导入自己的书。

TXT、Markdown、HTML、无加密 DOCX / EPUB 可以提取正文。导入后打开书籍，在 **原文** 中查看正文、整理章节；需要定位时，点击目录下方的 **跳到已读章节**。PDF、DOC、MOBI、AZW / AZW3 当前保留原件，不能据此进行精准摘录或让 AI 读取正文；复杂文件也可能退回原件模式。

分组在 **管理分组 ＋** 中新建或删除；书籍资料中的分组字段用于把书归入已有分类。点击封面可以替换图片并裁剪，替换文档则会创建新的原文版本，旧摘录保留原来的引用。

书籍右上角 **编辑** 中可查看文件、下载原件或新增版本。阅读正文时，轻点中间呼出工具栏并即时调整字体、字号；轻点左右边缘翻一屏，也可上下滚动。到章末自动显示上一章、目录和下一章。

## 4. 和 AI 讨论故事与看法

有两种常用入口：

- **从一段文字聊起：** 在原文中选中文字，保存摘录、记录想法或发起讨论。AI 可以围绕这段原文回应，你也能从引用跳回原文。
- **从整本书聊起：** 打开书籍的 **讨论 → 发起议题**，填写想交流的问题，例如“你认为主人公最后是在告别，还是在逃避？”然后在该议题中连续回复。

不同议题各自保存对话。讨论人物、情节和结局时，可以明确告诉 AI 阅读进度和是否接受剧透。AI 能否读到更多原文取决于可读正文和工具接入；它的解释与判断仍需要你结合原文辨别。

收到新议题或回复后，书本上会出现未读气泡；电脑侧栏的对应分组与书架入口也会汇总提示。打开对应议题会标记已读。发送状态不明时，先查看页面状态和原消息，避免把相同内容当作新消息重复发送。

## 5. 让 AI 主动找你聊书

打开 **设置 → 议题定时**，选择每天或每周、运行时间、时区和书籍范围。范围可以是全部可读书籍、正在读的书、某个分组或指定书籍。填写讨论偏好，例如：

> 从故事里的一个细节提出问题，先说说你的理解，再邀请我谈不同看法。关注人物关系，避开我尚未读到的结局。

开启 **启用定时任务** 并保存。保存只设置未来日程，不会立刻调用 AI；到时后端轮选一本范围内的可读书，建立议题并生成开场。回到书架查看未读气泡即可回应。

正式部署后，关掉网页或手机仍可运行。需要已保存且可用的 AI 配置、可读正文，以及公共账号的有效审批和足够额度。当前不会发送邮件或 Android 原生推送；普通模型也不会因为这个设置获得联网找书或执行任意任务的能力。没有可读书时跳过，错过太久的日程不会补跑多轮。暂停时关闭开关并保存。

运行规则和失败处理见 [定时共读说明](TOPIC-SCHEDULE.md)。

## 6. 调整成自己喜欢的样式

默认是牛皮纸背景、奶油色面板与简笔飞鸟。打开 **设置 → 美化设置**，按分类调整：

| 分类或区域 | 可以修改什么 |
| --- | --- |
| 主题配色、界面背景 | 主色、文字、桌面底色和背景图片；图片支持裁剪、缩放与位置调整 |
| 主面板 | 纸张、玻璃、磨砂材质，以及颜色、不透明度、透景柔化和颗粒感 |
| 内框美化 | 管理分组、表单、摘录、讨论等卡片的背景、文字、材质、圆角和边框 |
| 输入框 | 文字使用自动适配或自定义颜色，独立于主题文字色 |
| 原文阅读设置 | 字体、字号、行距、字距、段距、缩进、宽度、对齐及文字与纸张颜色 |

首页插图、书籍封面和讨论图标也可替换，上传后调整裁剪；首页插图可调显示大小。外观可以预览，满意后保存。点击外边关闭美化设置会取消尚未保存的调整。

外观只保存在当前浏览器或设备，换设备需要另设。书籍、摘录、讨论和已保存的 AI 配置保存在后端，登录同一账号即可继续使用。完整设置说明见 [设置与美化](SETTINGS.md)。

## 常见问题

**没有 Agent 能用吗？** 可以。连接支持所需工具调用的模型 API 即可；无需额外安装 Agent 框架。

**公共服务的 AI 请求配额就是模型余额吗？** 两者分别计算。公共服务按发往模型的 HTTP 请求计数，测试、失败和工具续答都可能占用额度，一条回复可能对应多次请求；实际模型费用仍由你的 API 账户承担。账号页显示获批额度，需要增加时再申请。

**AI 能替我把书放进书架吗？** 在 AI 接入的“可选书库工具”中开启文本新增权限，测试并保存后，可以让它把对话里已有或整理出的文字存为新书。默认关闭，仅新增 TXT / Markdown，不下载网上的书，不读取电脑文件，也不覆盖旧书。详见 [书库工具](AI-INTEGRATION.md#ai-能否放书进书库)。

**APK 能离线读书或自动弹通知吗？** 当前 APK 通过联网访问公共网页版，不提供离线提交或原生系统推送。

**自己部署后还能用制作者的 APK 吗？** 现成 APK 固定连接公共服务。自己的站点可用浏览器访问；需要连接自己站点的 APK 时，按 [Android 构建说明](../android-app/README.md)修改地址并自行构建。

**为什么模型说的内容和原文不符？** 先确认书籍已提取正文，再检查引用与模型工具接入。AI 的回答不保证正确；可以要求它标明依据，并回到原文核对。Mock 只演示界面，不代表真实模型效果。
