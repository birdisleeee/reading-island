# 设置、美化与阅读排版

书架的“设置”是统一入口：电脑在左侧导航底部，手机在搜索区下方。包括 AI 接入与人物预设、美化设置、议题设置；每个小项左上角可返回设置。书架分组管理留在外层书架菜单和电脑侧栏。

“新建分组”统一放在“管理分组”里面，电脑侧栏显示“管理分组 ＋”。电脑左下角显示已登录状态、用户名和固定用户 ID，点击可编辑用户名；手机从书架菜单打开“登录资料”。资料保存在自己的后端，换设备继续沿用。首次未设置名字时显示用户 ID。后续 AI 共读回合会收到用户名与 ID，名字用于称呼，ID 用于关联读者；改名不会更换书库。

保存中关闭编辑框不会撤销已提交的请求，但旧请求完成后不会关闭后来打开的编辑框或改变其草稿。书籍资料、登录资料和外观在保存期间继续修改时，会保留后续修改并提示尚未保存；新增书籍、摘录、议题、分组和章节提交期间暂时锁定本次内容，仍可关闭或取消。AI 配置在保存期间修改后需重新测试，旧保存不会清空新填的 Key。

## 美化设置

默认使用原创牛皮纸纹理、奶油色纸张面板、深棕文字和简笔飞鸟封面，书架默认插图也使用同款飞鸟。电脑主面板使用圆角边框，外层固定，内容在面板内部滚动；滚动条隐藏。可分别调整主题色、主题文字、面板色、桌面底色、背景图片和导航模糊程度。桌面底色是背景图片下方的颜色，纯色背景时直接可见。导航和设置抽屉使用当前背景图片的模糊版本，文字跟随主题文字。

面板材质可选纸张、玻璃和磨砂；支持面板不透明度和磨砂程度。玻璃提供轻微高光边框，磨砂使用细颗粒、柔化透景与透光层，可分别调节磨砂颗粒和透景柔化；纸张保持纸面样式。低不透明度时底下的背景会更明显。

美化设置按“主题配色”“界面背景”“主面板”“内框美化”“输入框”分区，每区有独立区域框。内框覆盖分组管理、AI 接入、表单、摘录和讨论卡片；可单独调整底色、文字颜色、纸张/玻璃/磨砂、透明度、柔化、颗粒、圆角和边框。默认底色跟随面板色，文字按内框底色自动选择深浅；也可以指定内框文字色或明确跟随全局主题文字。全局白色文字不会让浅色内框自动变成白字。输入框字色在“输入框”分区单独选择自动对比或自定义颜色，覆盖回复、搜索、书籍资料和设置表单；不随主题文字或内框文字变白。

修改即时预览；保存后刷新继续沿用，关闭或点击抽屉外侧会取消未保存修改。可恢复默认。图片支持 PNG/JPEG/WebP，最多8MiB；浏览器归一化后保存在自己实例的浏览器 IndexedDB，不上传到公共仓库。

选择背景或桌面插图后进入裁剪：拖动移动、双指或滑杆缩放、选择裁剪比例，点击完成应用到预览；取消裁剪保留原先图片。背景还需点击设置中的保存。已保存图片保留本地原图与裁剪参数，可用“调整裁剪”再次修改。桌面插图可单独调整显示大小，并用“保存大小”确认。裁剪输出最大边1920像素。

点击书内“这本书的讨论”左侧图标，可以替换图片、调整裁剪或恢复默认。点击裁剪完成后立即保存在当前浏览器，刷新继续沿用；取消裁剪不替换原图。

主题与阅读偏好是设备本地外观。书籍、摘录、讨论、加密 AI 配置和定时任务仍在后端；换设备不会丢书库，但需要分别设置各设备的外观。

书架每个分类右侧箭头控制展开/收起，选择保存在当前浏览器。点击分类标题仍可进入完整分类书架。

书籍角标显示未读讨论消息数。电脑左侧分类导航汇总该分类的未读数，“书架”入口汇总全部分类；搜索不会改变这些汇总。打开议题读取消息后，相应书籍、分类和书架提示同步减少。通知样式不改写后端的已读状态。

## 原文排版

进入原文后，点击标题栏右侧三个点，打开“阅读排版”抽屉，按“字体文字”“段落排版”“阅读背景”分区。可调整字体、字号、行距、字距、段距、首行缩进、最大阅读宽度、左右留白、对齐、文字颜色和背景。这里与全局主题分别保存。

这些调整只改变呈现，不改写冻结原文和摘录坐标。字号/留白较大时，手机正文仍会自动约束在屏幕内。

## 人物预设

设置 → AI 接入与人物预设 → 展开“人物预设”，填写身份、性格、语气及回复形式。例如：

> 你是一位温柔、有独立见解的共读伙伴。使用自然短段落，先回应我关注的内容，再提出一个值得一起想的问题；不把阅读讨论写成固定报告。

保存仍需先通过当前配置的连接测试。模型型讨论每次先收到共读基础规则、人物预设与共读风格，再收到议题资料和对话。连接测试验证接口与原文工具，不承诺模型一定按人物描述表现。预设不替换已有 Webhook Agent 自己的人格或长期记忆。

定时任务见[定时议题说明](TOPIC-SCHEDULE.md)。
