# 设置、美化与阅读排版

书架的“设置”是统一入口：电脑在左侧导航底部，手机在搜索区下方。包括 AI 接入与人物预设、美化设置、议题设置和书架分组管理。

## 美化设置

默认使用原创牛皮纸纹理、奶油色面板与深棕文字。可分别调整主题色、主题文字、面板色、底色、背景图片和导航模糊程度。桌面导航使用当前背景图片的模糊版本，导航文字跟随主题文字。

修改即时预览；保存后刷新继续沿用，直接关闭抽屉会取消未保存修改。可恢复默认。图片支持 PNG/JPEG/WebP，最多8MiB；浏览器归一化后保存在自己实例的浏览器 IndexedDB，不上传到公共仓库。

主题与阅读偏好是设备本地外观。书籍、摘录、讨论、加密 AI 配置和定时任务仍在后端；换设备不会丢书库，但需要分别设置各设备的外观。

书架每个分类右侧箭头控制展开/收起，选择保存在当前浏览器。点击分类标题仍可进入完整分类书架。

## 原文排版

进入原文后，点击标题栏右侧三个点，打开“阅读排版”抽屉。可调整字体、字号、行距、字距、段距、首行缩进、最大阅读宽度、左右留白、对齐、文字颜色和背景。这里与全局主题分别保存。

这些调整只改变呈现，不改写冻结原文和摘录坐标。字号/留白较大时，手机正文仍会自动约束在屏幕内。

## 人物预设

设置 → AI 接入与人物预设 → 展开“人物预设”，填写身份、性格、语气及回复形式。例如：

> 你是一位温柔、有独立见解的共读伙伴。使用自然短段落，先回应我关注的内容，再提出一个值得一起想的问题；不把阅读讨论写成固定报告。

保存仍需先通过当前配置的连接测试。模型型讨论每次先收到共读基础规则、人物预设与共读风格，再收到议题资料和对话。连接测试验证接口与原文工具，不承诺模型一定按人物描述表现。预设不替换已有 Webhook Agent 自己的人格或长期记忆。

定时任务见[定时议题说明](TOPIC-SCHEDULE.md)。
